Lexicon Curator Engine

Parse a lexicon, normalize it deterministically, validate it, and emit an immutable, content-addressed JSON-LD graph — all in this tab, no server.

Offline mode: online dictionary lookups (every entry is deferred) and the interactive definition-selection interface are deferred adapter/curation phases (§4.2 / §8.3). What runs here is the full deterministic core: parse (§4.4) → normalize (§4.1) → derive phases (§3.3) → validate (§7) → mint content-ids (§5) → ExportManifest (§5.4).
